## ✦ About Me

<table>
<tr>
<td width="55%" valign="top">

I am **Samanway Koley**, a **Frontend Developer** focused on turning approved UI designs into responsive, interactive, and maintainable web interfaces.

I work with **HTML, CSS, JavaScript, jQuery, and Bootstrap** to build clean, consistent frontend experiences across devices.

> **I am not a UI/UX designer.**  
> I use **Figma, Adobe XD, Sketch, and Photoshop** strictly to inspect design files, understand spacing and typography, collect assets, and implement the provided UI with precision in code.

</td>
<td width="45%" valign="top">

### What I Build
- Responsive website interfaces
- Design-to-HTML implementations
- Bootstrap-based layouts
- Interactive jQuery components
- Cross-browser frontend experiences

### What I Focus On
- Pixel-perfect design translation
- Responsive behavior
- Clean, semantic structure
- Maintainable stylesheets

</td>
</tr>
</table>
